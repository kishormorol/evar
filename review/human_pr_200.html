Example: The comment says, “Empty names are accepted.” BEFORE has no check. AFTER rejects empty names. Answer Yes, describe the problem as “The function accepts an empty name,” and select “Missing check or validation.”

Choose No if:
  • The comment is only praise, a question, or a style preference.
  • The excerpts do not show enough code to decide.
  • The problem is not present in BEFORE or is still present in AFTER.
  • The problem does not fit one of the categories in the form.
What do the problem categories mean?
Opposite behavior
The code does the opposite of what it should do.
Missing check or validation
A necessary condition, validation, or early return is missing.
Wrong function relationship
The problem is about which function calls, wraps, awaits, or delegates to another.
Wrong cause or location
The behavior is real, but the comment points to the wrong code or cause.
Outdated evidence
The comment refers to code or behavior that is no longer in the compared snapshot.
