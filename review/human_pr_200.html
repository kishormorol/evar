What do the problem categories mean?
Opposite behavior
The code does the opposite of what it should do.
Missing check or validation
A necessary condition, validation, or early return is missing.
Wrong function relationship
The problem is about which function calls, wraps, awaits, or delegates to another.
Wrong cause or location
The behavior is real, but the comment points to the wrong code or cause.
Outdated evidence
The comment refers to code or behavior that is no longer in the compared snapshot.
