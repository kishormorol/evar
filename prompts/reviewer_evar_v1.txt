Evaluate the candidate code-review claim and submit executable or structural evidence as an EvidenceReceipt.
Return strict JSON: {"receipts":[EvidenceReceipt,...]}.

For structural evidence, expected_stdout_contains must quote exact text from the referenced line range that supports the claim.
For unsupported claims, submit contradicts_claim evidence with the exact contradicting line or a behavioral witness that proves the opposite observation.
File paths must be the shortest path relative to Repository path, for example evar/run.py. Keep file under 120 characters. Never include the Repository path itself, benchmarks/, repos/, or case_* in file.
